# Darkest Dungeon 1 trinkets: rarities, drops, the Nomad Wagon and 47 trinkets

Researched on 2026-10-27 for the Godot project `darko-dungo`. We are adding **Darkest Dungeon 1 (DD1, 2016, with DLC)** trinkets under their real names. This document gives the raw DD1 data to translate from:

- the trinket rarities, with sell values;
- how rarity and dungeon level decide what drops, and where trinkets come from;
- the Nomad Wagon: stock, prices and upgrades;
- 16 class trinkets for our eight classes (Crusader, Grave Robber, Arbalest, Vestal, Man-at-Arms, Plague Doctor, Jester, Flagellant), 25 generic trinkets and 6 Ancestral trinkets, with every effect line.

The translation into our engine is not done here.

## How to read this document

Every claim is tagged with its source:

| Tag | Meaning |
|---|---|
| **(wiki)** | darkestdungeon.wiki.gg: the Trinkets, Nomad Wagon, Inventory and Districts pages. It reflects the current game (v1.x with DLC). See the access caveat below. |
| **(data)** | The current DD1 game files, as extracted by **two independent third-party repositories**, [D-T] and [D-W] (below). "(data)" means both agree. Where only one has a trinket, the tag names it: **(D-T)** or **(D-W)**. |
| **(wiki+data)** | The wiki and both data extractions give the same value. Every trinket row in section 4 is this, unless marked otherwise. |
| **(data-2016)** | The 2016 game-data snapshot in Reinisch's Unity port [D-U], also used by [darkest-dungeon-town.md](darkest-dungeon-town.md). It is the **only** source for loot-table weights. Trinket stats in it are out of date (see Conflicts). |
| **(inferred)** | My own reading or arithmetic. Treat as a suggestion, not fact. |

**Conflict** marks places where sources disagree; both values are given. **Unconfirmed** marks things no source states.

> **About [D-T].** `bluefireF5ran/dd-team-builder`, a DD1 team planner. Its file `src/data/trinketEffects.js` is marked GENERATED by `scripts/importTrinketEffects.js`. That script reads the game install's `trinkets/*.entries.trinkets.json` (which buffs a trinket grants), `shared/buffs/*.buffs.json` (what each buff does) and the English tooltip templates in `localization/*.string_table.xml`. It sweeps the DLC folders too (Crimson Court, Color of Madness, Shieldbreaker, Fire's Edge). It also lists the set bonuses. Effect text is rendered in the game's own tooltip wording. The game version is not stated.

> **About [D-W].** `WizardMeow/darkest-dungeon-trinkets`, a Chinese-language trinket catalogue. Its `public/data/游戏饰品表.csv` ("game trinket table") has English name, internal ID, rarity, class and stats for 278 trinkets. Each row names the game file it came from (e.g. `trinkets/base.entries.trinkets.json`, `dlc/580100_crimson_court/.../flagellant.entries.trinkets.json`). The README says the stats come "from the local install's definitions, without Workshop mods". The CSV has no Arbalest Vengeful/Sturdy Greaves and no Eternity's Collar; otherwise it covers every trinket used here.

> **About [D-U].** The 2016 snapshot has the trinket entries (`JsonTrinkets.json`), buffs, loot tables, quests, curios and the Nomad Wagon building and upgrade files. Many trinket numbers have changed since (see Conflicts). So it is used only for loot weights, quest-reward tables and the stat meanings of buff types. Those parts have no newer source.

> **Source access.** wiki.gg was read through WebFetch, which returns a model-written summary of the page, not the raw wikitext. A scripted raw download was not attempted again: it got HTTP 403 before, and this session's permission check blocked it. So the wiki's wording passed through a summariser. Every trinket number below also matches both data extractions, so the numbers are safe; the exact wiki wording is less certain. The GD-JM/darkest-dungeon-rebalance repo has **no** trinket data files, only design notes. Fandom was not consulted.

### Notation used in the trinket tables

Effect lines use the game's tooltip wording, with ASCII signs (`+`, `-`), separated by `;`. The meaning of each stat term comes from the buff `stat_type` in the data (data-2016 buff definitions; the term-to-type mapping still holds in the current text (inferred)):

| Term | Meaning (data stat type) |
|---|---|
| **DMG** | Multiplies the hero's weapon damage range (`combat_stat_multiply` on `damage_low` and `damage_high`, two buffs). How it stacks with other modifiers is in [darkest-dungeon-combat.md](darkest-dungeon-combat.md). |
| **ACC**, **DODGE** | Flat points added (`attack_rating` / `defense_rating`, stored as 0.04 for +4). |
| **CRIT** | Crit chance in percentage points. |
| **PROT** | Flat percent protection added (`protection_rating` +0.05 = +5% PROT). |
| **SPD** | Flat speed. |
| **MAX HP** | Percent of max HP (`combat_stat_multiply max_hp`). |
| **Stress** | Stress **received**, as a percent (`stress_dmg_received_percent`). "-10% Stress" = takes 10% less stress. It is a multiplier, so no 0–200 to 0–10 scale conversion is needed (inferred). |
| **Healing Skills** | Healing the wearer's skills give (`hp_heal_percent`). |
| **Healing Received** | Healing the wearer receives (`hp_heal_received_percent`). |
| **X Skill Chance** | Added to the base chance of the wearer's X effects: Stun, Blight, Bleed, Debuff or Move (e.g. `stun_chance`). |
| **X Resist** | The wearer's resistance (`resistance`, e.g. `death_blow`). |
| **Death Blow Resist** | Chance to survive a hit while at Death's Door. |
| **Virtue Chance** | Chance of a virtue instead of an affliction at 100 stress. |

**Conditions** are DD1 buff rules (data-2016 `rule_type`), always written as part of the line:

- "if in position N" (`in_rank`, counted from 1 here, 0 in the data);
- "if HP below X%" or "above X%";
- "at Death's Door";
- "on First Round" / "after First Round";
- "Melee Skills" / "Ranged Skills" (`meleeonly` / `rangedonly`);
- "vs Marked", "vs Blighted" (the target's state);
- "if Torch above/below N".

## TL;DR: the numbers you will most likely need

```
Rarity        Wagon buy  Sell   Sellable  Curio/chest trinket roll, weight by level   Quest reward (Short/Med/Long)
                                          Apprentice  Veteran  Champion+Darkest
Very Common    5,000      750   yes          45          20         15
Common         7,500    1,125   yes          40          35         30              Apprentice Short
Uncommon      10,000    1,500   yes          10          35         35              Appr Med,  Vet Short
Rare          15,000    2,250   yes           5           8         12              Appr Long, Vet Med,  Champ Short
Very Rare     25,000    3,750   yes           0           2          5              Vet Long,  Champ Med, every boss quest
Ancestral     not sold  7,500   yes           0           0          3              Champ Long only
Trophy        not sold  -       no            (Champion boss quest only, on top of the Very Rare)

Prices and sell values: wiki (sell value = 15% of the wagon base price).
Roll weights and quest table: data-2016; the quest table matches the wiki's "one rarity step per level or length".
```

- **Drop rule.** A trinket roll first picks a rarity from the level's weights, then a trinket of that rarity (data-2016; the second step's method is inferred).
  - Very Rare cannot roll in Apprentice loot. Ancestral rolls only in Champion and Darkest loot.
  - Quest rewards are one fixed rarity per level and length.
- **Nomad Wagon.**
  - Stock: **2** trinkets a week at base; Wagon Size raises it to **4 / 6 / 8 / 12** for **10 / 26 / 42 / 58 Crests**.
  - Price: Merchant Network takes **-10% per level, 5 levels (-50%)**, for **8 / 18 / 28 / 38 / 46 Crests**.
  - Each slot's rarity: Very Common 33%, Common 28%, Uncommon 22%, Rare 11%, Very Rare 6%. **No Ancestral.**
  - Stock refreshes weekly. Selling returns 15% of the base buy price.
  - (wiki; base stock of 2 from data-2016 and the wiki Inventory page; per-slot rolling inferred.)
- **"Ancestor's ..." trinkets are not boss drops.** They come from long Champion quests and rare Champion loot. The boss trinkets are the **Trophies** (section 1).

- **Sell value = 15% of the base buy price** for every Wagon rarity, e.g. 750 = 15% of 5,000 (inferred from the wiki's two tables, and from the data-2016 prices 5,000 / 7,500 / 10,000 / 15,000 / 25,000 / 50,000). Ancestral 7,500 = 15% of 50,000 fits too.
- **Unique trinkets.** Ancestral trinkets are unique: "once you own one, you cannot find a duplicate". A lost one returns only through the Shrieker's Perch quest (wiki). The data's `limit 1` is set on Ancestral, Trophy, Crystalline, Shrieker, Crimson Court, Thing, Ringmaster, Collector heads, backer trinkets and eleven Very Rares (D-T). The class and generic trinkets in section 4 have no limit (data).
- **Trophies** re-appear in the hamlet inventory if lost (wiki).
- **History.** Ancestral trinkets outside the Ancestor set were later reclassified as Very Rare (wiki).

## 2. Drops by dungeon level

DD1 dungeon levels: Apprentice = 1, Veteran = 3, Champion = 5, Darkest = 6 (data-2016, see [darkest-dungeon-town.md](darkest-dungeon-town.md) 7.4).

### 2.1 Quest completion reward (1 trinket per completed quest)

| Level | Short | Medium | Long |
|---|---|---|---|
| Apprentice | Common | Uncommon | Rare |
| Veteran | Uncommon | Rare | Very Rare |
| Champion | Rare | Very Rare | Ancestral |

- Source: data-2016 `trinket_chance_table`, one rarity at weight 1 per cell, so the rarity is fixed, not rolled. The wiki confirms the rule: rarity rises "one level" per step of difficulty or length, from Common for short Apprentice to Ancestral for long Champion.
- The table has an empty row for level 6. Darkest Dungeon quests give no table trinket (data-2016). Instead, "certain areas in the Darkest Dungeon have chests guaranteed to contain Ancestral trinkets" (wiki).
- **Boss quests** always give **1 Very Rare** (wiki; data-2016 `additional_trinket_completion_rewards: very_rare`).
- **Champion boss quests** also give that boss's **Trophy**. Trophies are "only offered as quest rewards when defeating a Champion-level boss encounter" (wiki). The data-2016 Champion Necromancer quest lists 9,000 gold + the `boss_necromancer` trinket + 1 Very Rare (data-2016).
- **Region-limited rewards.** "Some trinkets can be found as a quest reward for only a specific region. These can still be bought from the Nomad Wagon." (wiki) Section 4 notes which chosen trinkets have a region.

### 2.2 Curio and chest loot (table `T`)

When a loot roll reaches the trinket table, the rarity is rolled by dungeon level. The weights sum to 100, so they are percents (data-2016):

| Rarity | Apprentice (1) | Veteran (3) | Champion (5) | Darkest (6) |
|---|---|---|---|---|
| Very Common | 45 | 20 | 15 | 15 |
| Common | 40 | 35 | 30 | 30 |
| Uncommon | 10 | 35 | 35 | 35 |
| Rare | 5 | 8 | 12 | 12 |
| Very Rare | 0 | 2 | 5 | 5 |
| Ancestral | 0 | 0 | 3 | 3 |
| Ancestral (Shambler) | 0 | 0 | 0 | 0 |

How often a curio or chest reaches `T` (data-2016 loot tables and `Curios.csv`; percentages inferred from the weights):

| Table | What it rolls | Trinket chance per draw | Curios that draw it (data-2016) |
|---|---|---|---|
| `A` (treasure) | gold 14, gems 8, heirlooms 12, supplies 7, trinket 2 | 2/43, about **4.7%** | Strongboxes, Barnacle Crusted Chest, Iron Maiden, Lost Luggage, Old Tree, Pile of Bones (1–3 draws by item used) |
| `CT` | gold 9, trinket 1 | **10%** | Confession Booth, Dinner Cart, Giant Oyster, Locked Sarcophagus, Mummified Remains |
| `GT` | gems 9, trinket 1 | **10%** | Cosmic Spiderweb, Decorative Urn, Giant Fish Carcass |
| `T` direct | always a trinket | **100%** | The quest-goal strongbox ("Found the sought after treasure!": 3 battle-loot draws + 1 trinket); the tutorial chest |

- **Low light gives extra treasure draws:** up to 95% chance of an extra `A` draw per chest at torch 0, falling to 0 at torch 76+ (data-2016 `darkness_bonuses`; see [darkest-dungeon-town.md](darkest-dungeon-town.md) 8.1).
- A table `Tbase` (nothing 3, `T` 2) also exists; where it is used was not checked (data-2016).
- **Within a rarity**, which trinket is picked is not in the data. Uniform among eligible trinkets is the natural reading (inferred). Eligible likely means: not over its `limit`, a class you have, and the region rule. All three are **unconfirmed**.

### 2.3 Battle loot and enemy drops

- Ordinary battle loot (table `B`) is gold or gems only, never trinkets (data-2016).
- **Specific enemies** have their own trinket tables:
  - **Madman:** a 5 : 1 roll between supplies and `T_MADMAN`. `T_MADMAN` is Very Common / Common / Uncommon / Madman box at 1 / 1 / 1 / 1 (data-2016). That is about 4.2% per kill for a music box (inferred), which matches the wiki's "about 4% chance".
  - **Collector:** 3 : 1 between a Trapezohedron and a Collector head, so 25% per kill (data-2016; arithmetic inferred). The wiki says "sometimes".
  - **Shambler:** always one Ancestral (Shambler) trinket (data-2016 `SHAMBLER` table; wiki: five trinkets "can only be dropped by a Shambler or Shuffling Horror").
  - **Shrieker:** drops Shrieker trinkets when defeated in *Shrieker's Prize* (wiki).
- A town-invasion sack table rolls Very Rare or Ancestral at 1 : 1 (data-2016 `T_INCURSIONSACK`).
- An Antiquarian camping table rolls VC/C/U/R/VR at 10 / 7 / 5 / 2 / 1 (data-2016 `T_ANTIQ_CAMP`). Neither applies to our cast (inferred).

### 2.4 Other sources (brief)

- The Nomad Wagon (section 3).
- Tavern gambling can win a trinket; Tavern side effects can lose one. See [darkest-dungeon-town.md](darkest-dungeon-town.md) 9.3 (wiki).
- The *Fire's Edge* **Craftworks** district gives one random trinket a week: Common 30% … Very Rare 10% (wiki Districts).
- Equipped trinkets on a hero who dies are lost unless the battle is won (wiki).

## 3. Nomad Wagon

A Crest-only building that sells a weekly stock of trinkets (wiki). Its unlock fields are `highest_dungeon_level 2` and `number_of_quests_finished 0` (data-2016). [darkest-dungeon-town.md](darkest-dungeon-town.md) 1 notes a conflict with the wiki's "week 4".

### 3.1 Upgrade lines

| Line | Level | Effect | Crests (wiki) | Crests (data-2016) |
|---|---|---|---|---|
| **Wagon Size** | 0 | 2 trinkets per week | — | — |
| | 1 | 4 trinkets per week | 10 | 17 |
| | 2 | 6 | 26 | 46 |
| | 3 | 8 | 42 | 74 |
| | 4 | 12 | 58 | 103 |
| **Merchant Network** | 1–5 | -10% buy price per level (-50% at level 5) | 8 / 18 / 28 / 38 / 46 | 14 / 31 / 48 / 65 / 82 |

- No gold cost (data-2016 `gold 0`; wiki lists Crests only).
- **Use the wiki costs.** They are the current game's; [darkest-dungeon-town.md](darkest-dungeon-town.md) 1.9 uses them too. The 2016 data was dearer (**conflict**).
- The base stock of 2 comes from data-2016 (`number_of_slots 2`) and the wiki Inventory page ("Default 2 slots"). The Nomad Wagon page itself does not state it.

### 3.2 Buy prices by Merchant Network level (wiki)

| Rarity | Base | MN1 | MN2 | MN3 | MN4 | MN5 | Sell value |
|---|---|---|---|---|---|---|---|
| Very Common | 5,000 | 4,500 | 4,000 | 3,500 | 3,000 | 2,500 | 750 |
| Common | 7,500 | 6,750 | 6,000 | 5,250 | 4,500 | 3,750 | 1,125 |
| Uncommon | 10,000 | 9,000 | 8,000 | 7,000 | 6,000 | 5,000 | 1,500 |
| Rare | 15,000 | 13,500 | 12,000 | 10,500 | 9,000 | 7,500 | 2,250 |
| Very Rare | 25,000 | 22,500 | 20,000 | 17,500 | 15,000 | 12,500 | 3,750 |

- The discount is taken off the base price; the levels add (data-2016 `discount_percent 0.10` × 5; wiki prices).
- The sell value is fixed at 15% of the **base** price, whatever was paid. At MN5 that is 30% of the price paid (inferred).
- The *Nomad New Year* town event halves trinket prices, e.g. Very Common 2,500 and Very Rare 12,500 at base (wiki).

### 3.3 How the stock is chosen

- **Rarity per slot:** Very Common 33%, Common 28%, Uncommon 22%, Rare 11%, Very Rare 6% (wiki "spawn chance", which sums to 100%). The page does not say it is rolled per slot; per-slot is the natural reading (inferred).
- **Only those five rarities.** The wiki lists no Ancestral, Trophy or special rarity for the Wagon, and Crystalline trinkets are bought at the Jeweler with Comet Shards instead (wiki). So the Wagon never sells Ancestral (inferred).
- **Class trinkets** share the five rarities, so they can appear. Region-limited trinkets "can still be bought from the Nomad Wagon" (wiki). Whether a class you have never recruited can appear is **unconfirmed**.
- **No dependence on dungeon level or hamlet progress** is stated anywhere (wiki "not stated"). Treat the odds as fixed (inferred).
- **Restock** every week (wiki). The stock is shown sorted by price, highest first, in the Unity port. That is the port's own code, not game data, so it is **unconfirmed** for DD1.
- **Patch history.** [darkest-dungeon-town.md](darkest-dungeon-town.md) 1.9 cites a Feb 2017 patch that made Rare trinkets rarer in the Wagon. I could not find that patch note this time (**unconfirmed**).

## 5. Conflicts and gaps between the sources

- **The 2016 trinket stats are out of date.** Examples (data-2016 vs today's wiki+data):
  - Paralyzer's Crest +40% Stun Skill Chance, now +20%.
  - Warrior's Bracer +15% melee DMG, now +10%.
  - Martyr's Seal +75% DMG at Death's Door, now +60%.
  - Quickening Satchel also had a Move Resist line.
  - Life Crystal and Poisoned Herb were **Rare**, now Uncommon.
  - Region tags moved too: Dodge Stone and Berserk Charm had none, now Ruins and Warrens.

  So no trinket number here comes from data-2016. Its loot and quest tables may also have changed; no newer copy was found (**unconfirmed for the current build**).
- **Conflict: Nomad Wagon upgrade costs.** Wiki 10/26/42/58 and 8/18/28/38/46 Crests; data-2016 17/46/74/103 and 14/31/48/65/82. Use the wiki.
- **Conflict: Wagon maximum stock.** The Nomad Wagon page and data-2016 say 12 at Wagon Size 4. The wiki Inventory page says "max 16 (upgradable)". No district or event that adds slots was found (wiki Districts). 16 may be the UI's slot capacity (inferred). Use 12.
- **Conflict: Collector and Madman price.** data-2016 has buy price 1,000 for both, which would sell for 150. The wiki's sell value today is 2,250, the same as a Rare (base 15,000) (inferred). Irrelevant if we ignore those rarities.
- **Conflict: Sickening Satchel's condition** (alternates only): the wiki and D-T say "vs Blighted" (the target); D-W says when the wearer is Blighted. D-W reads the same `status` rule as self-status on Bedtime Story too, so D-W's reading of that rule type is probably the error (inferred). Prefer "vs Blighted".
- **Gap: Vengeful Greaves** is missing from D-W's CSV (as are Sturdy Greaves and Eternity's Collar). It rests on the wiki and D-T, which agree.
- **Gap: wiki wording.** It passed through WebFetch's summariser (see Source access). Every number agrees with two data extractions, but small wording differences (e.g. line order) may exist.
- **D-T's own inconsistency:** its header says the Ancestor's Musket Ball has limit 3, but its entry says limit 1. The wiki says all Ancestral trinkets are unique. Use 1.

## 6. Could not confirm

- **Current-build loot weights** (table `T`, tables `A`/`CT`/`GT`) and the quest-reward table. Only the 2016 snapshot has them. The wiki's "one rarity step" rule and the "about 4%" Madman box both match the 2016 numbers, which suggests little change.
- **How a trinket is picked within a rarity:** uniform or weighted. And whether locked classes, unique limits and region tags remove trinkets from loot rolls, not just from quest rewards.
- **Whether region-tagged trinkets also drop only in their region** from curios. The wiki mentions only quest rewards.
- **Nomad Wagon:**
  - that each slot rolls its rarity independently (vs. a fixed spread);
  - whether stock depends on dungeon level;
  - whether duplicates can appear in one week's stock;
  - whether locked or un-recruited classes' trinkets appear.
- **The Feb 2017 Wagon patch** cited in [darkest-dungeon-town.md](darkest-dungeon-town.md); not found again.
- **The base stock of 2** is from data-2016 and the wiki Inventory page, not from the Nomad Wagon page.
- The **sell value of Ancestral (Shambler)** trinkets: the wiki's table has only "Ancestral", so 7,500 is assumed.
- The **game version** of the [D-T] and [D-W] extractions. Both include all DLC folders, so they look current (inferred).
